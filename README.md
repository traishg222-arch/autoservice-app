# Онлайн-запись для автосервиса (PWA)

Клиент выбирает услугу, дату и время, оставляет имя, телефон и авто. Владелец в `/admin` ведёт заявки, услуги, цены и внешний вид.
Без сборки и без зависимостей: нужен только **Node.js 18+**.

## Запуск

```bash
ADMIN_PASSWORD=ваш-пароль npm start
```

- Клиентам: `http://localhost:3000`
- Владельцу: `http://localhost:3000/admin`

Переменные можно хранить в файле: скопируйте `.env.example` в `.env` и запускайте `node --env-file=.env server.js` (Node 20.6+).

Пароль из `ADMIN_PASSWORD` используется один раз, при создании базы. Без него будет `admin123` (сервер предупредит). Сменить позже: **Настройки → Безопасность** или `npm run set-password -- НовыйПароль`.
Проверка API: `npm test`.

## Как адаптировать под нового клиента

Один код, отдельная копия развёртывания на клиента.

1. Скопируйте `config/brand.default.json` (пример: `brand.example-tyres.json`): название, слоган, телефон, адрес, цвета, часы работы, услуги и цены.
2. Запустите с `BRAND_FILE=./config/brand.клиента.json` и отдельным `DATA_DIR`. Файл читается один раз, при создании базы.
3. Дальше владелец сам правит всё в `/admin`: название, логотип, цвета, услуги, цены, график.

Иконка приложения по умолчанию (колесо) рисуется в цветах бренда. Загруженный логотип заменяет её и на сайте, и на телефоне клиента.

## Как работает запись

- Окно записи = «Длина окна» из настроек; «Постов» = сколько машин можно принять в одно время.
- Отменённая заявка освобождает время. Прошедшее время скрыто.
- Часовой пояс задаётся в настройках, иначе «сегодня» на сервере и у клиента разойдутся.

## Размещение в интернете

Нужен хостинг с постоянным диском: данные лежат в `DATA_DIR/db.json`. HTTPS обязателен для установки PWA, у перечисленных ниже он есть.

**Render / Railway / Fly.io (проще всего)**
1. Загрузите проект в GitHub.
2. Создайте Web Service: команда запуска `node server.js`.
3. Добавьте постоянный диск, например в `/data`, и переменные `DATA_DIR=/data`, `ADMIN_PASSWORD=...`.
4. Подключите свой домен в настройках сервиса.

**Docker**
```bash
docker build -t autoservice .
docker run -d -p 3000:3000 -v autoservice-data:/data -e ADMIN_PASSWORD=пароль autoservice
```

**Свой VPS**: `node server.js` под `pm2` или systemd, перед ним Caddy (`your.domain { reverse_proxy localhost:3000 }`), HTTPS выдаётся автоматически.

Бесплатные тарифы без постоянного диска стирают данные при перезапуске: для реального клиента такой вариант не подходит.

**Резервная копия**: копируйте `db.json` (и `logo-*.png`) из `DATA_DIR`.

## Уведомления в Telegram (по желанию)

Создайте бота у @BotFather, узнайте свой chat id и задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Новые заявки будут приходить сообщением.

## Структура

```
server.js           маршруты API и раздача файлов
lib/                хранилище, слоты, авторизация, валидация, иконка
config/             стартовый бренд клиента
public/             клиентское приложение (index.html), панель (admin.html), sw.js
scripts/            автотест и смена пароля
```

Ограничения: хранилище — JSON-файл (сотни записей в месяц для него нормально; при росте перейдите на SQLite), сервер один. Ограничение частоты запросов хранится в памяти процесса.
